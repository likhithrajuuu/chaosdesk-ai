# Upload button unresponsive in Safari

Document ID: KB-002
Status: current

Known issue:
The upload button may become unresponsive in Safari.

Workaround:
Try uploading the same file using Chrome or Firefox.

Scope:
This workaround applies to an unresponsive upload button in Safari.
It does not establish a fix for failed uploads in other browsers
or for a service-wide outage.

If the workaround fails, collect the browser version, error message,
and approximate time of the failure for engineering investigation.
